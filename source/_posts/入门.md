### Chapter 1 · 准备

无论任何工程，第一步都是熟悉软件。画板子尤其需要熟悉软件本身，以及相关偏好设置，否则可能会和别人做成完全不同的两份工作。

比如最简单的对齐问题，如果每次都要找很久，甚至要手动对齐，那么效率会大幅降低。相反，当我们熟悉快捷键后，就可以非常迅速且流畅地完成这类操作。

下面是实用度比较高的几个 KiCad 10.0 快捷键（版本不同可能略有差异）。

*低级错误提醒：记得调整输入法。*

| 快捷键 | 常用位置 | 作用 |
| --- | --- | --- |
| `M` | 原理图 / PCB | 移动器件、封装或图形对象。 |
| `R` | 原理图 / PCB | 旋转当前选中的对象。 |
| `X` | PCB 编辑器 | 开始布线，连接焊盘和网络。 |
| `V` | PCB 编辑器 | 放置过孔，常用于换层走线。 |
| `B` | PCB 编辑器 | 重新填充覆铜区域。 |
| `Ctrl + F` | 全局 / 编辑器 | 搜索元件、网络或页面内容。 |

其次，关于 PCB 的一些基础知识也是必须了解的，~~按邹老师的说法原本不知道是要回家或者枪毙的~~。以防您不知道，我还是用最直白、最不绕弯子的方式阐释一下：

1. 原理图中有两个该连上的地方没有连上怎么办？

   请使用网络标签，或者其他类似方式。它可以让原理图更清晰，也能避免大量跨页面飞线。

2. 一个运放放置之后为什么出来两个？

   注意，这可能是双运放。不要把同一组运放拆开、搞混，或者忘记另一半还在原理图里。

3. 如果暂时不知道铺铜等操作的意义怎么办？

   不知道也没有关系，先牢记这些是必要步骤即可。但是请务必运行 *ERC* 和 *DRC*。如果是报错，一定要修改；警告有可能无关痛痒，但有时候真的会救命。

### Chapter 2 · 开始

对于一个画板哥，我想完整的开发流程无疑是：

```text
电路设计 -> 元件选型 -> 原理图 -> PCB -> 生产
```

但是介于本篇的定位与本人的实力，并不能从头到尾进行完整教学。所以这里更推荐一条容易入手、并且能提高短时生产力的学习路线。

#### 原理图

1. 如果您是在培训期间（或附近）才看到这个，不要一开始就完全自己设计电路。

   最开始别说设计电路了，有人抄都能抄错，比如 *射随器* 没注意画反。所以我的建议是：优先保证完成度。实际一个月内，试错成本很高。最开始邹老师会给出电路的原理图，主要目标其实是根据原理，把原理图正确地画出来。

   如果您是在培训之前就看到这篇文章，那么我也建议您先去开源广场学习一些内容，再完全开始自己设计，~~或者您立刻关闭本文从头开始学~~。

2. 在首次画原理图时，我们会遇到以下两个主要问题。

   **问题一：找不到对应芯片的封装怎么办？**

   不算方法的方法：直接看芯片是什么封装，比如 SOIC-8，然后先放一个相同封装的器件解决问题。

   方法一：如果您十分信任我并下载了 *华秋版*，那么很幸运，可以直接利用在线库进行搜索。如果在线库也没有，那么大概会遇到第二个问题。

   方法二：去在线平台搜索对应芯片的封装。下面推荐两个我用过的网站：

   - [SnapEDA](https://www.snapeda.com/)
   - [Ultra Librarian](https://www.ultralibrarian.com/)

   **问题二：发现买不到对应芯片，或者芯片涨价严重怎么办？**

   方法一：尝试更换封装。同一型号芯片的不同封装，核心功能差别通常不会特别大。

   方法二：尝试更换芯片。这一点会在后面进行讲解。

#### PCB

进入 PCB 部分，往往是初学者最头疼、也最有些恐惧的地方。完全不用担心，因为第一次多多少少都会出错。

很多时候，板子上其他地方可能也不太合理，但真正导致板子完全没法用的，往往是一些特别低级的错误。我尝试列举两个非 DRC 报错的问题：

- 网络标签大小写写错，导致本来该有的飞线没有出现。
- 电源线画得太细，导致供电不足。

所以，最主要的不是让 layout 更加合理，也不是让布线更加美观。第一优先级永远是检查功能是否完整。

相信各位一定听说过 PCB 设计的各种原则，有时候感觉就像规则怪谈。其实我也不全懂，只能尽我所能列举几个简单且易执行的原则：

1. 尽量顶层布线，底层线越少越好。
2. 信号线一般使用 0.25 mm 即可；电源线要根据电流大小和散热问题决定。进阶方法是直接铺铜，后续介绍。
3. 反馈网络尽量离输出部分近一些，去耦电容尽量离供电引脚近一些。
4. 连线短且直最好。本篇暂不考虑阻抗匹配问题，~~实际也没啥人考虑~~。
5. 不要为了放置过孔，而随意调小过孔大小、布线最小间距等参数。生产商可能没有那个工艺，~~得加钱~~。

如果您看到这里，其实已经可以着手开展工作了。后续更多是《无关痛痒》的东西。
